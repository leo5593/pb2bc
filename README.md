# PocketBeagle 2 Black Cape

Convert the PocketBeagle 2 to an BeagleBone Black like board with native ethernet support.

## Objective

Use the PocketBeagle 2 in project that currently use the BeagleBone Black.

# Design

The schematics and pcb are designed with EasyEDA for easy web based design and straightforward production with JLCPCB.

For cost effective production :
- Single sided placement
- Minimum package 0402
- Use basic components to reduce extended components fee.

https://jlcpcb.com/capabilities/pcb-assembly-capabilities
